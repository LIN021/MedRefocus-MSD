# Third-party software and data

The MIT license in this repository covers the MedRefocus implementation. Dependencies are installed separately; their source code and licenses remain with their owners.

| Component | Use | Upstream |
|---|---|---|
| nnU-Net | Global/Auxiliary observation and preprocessing | [MIC-DKFZ/nnUNet](https://github.com/MIC-DKFZ/nnUNet), Apache-2.0 |
| surface-distance | Area-weighted surface metrics | [google-deepmind/surface-distance](https://github.com/google-deepmind/surface-distance), Apache-2.0 |
| PyTorch | Neural training/inference | [pytorch/pytorch](https://github.com/pytorch/pytorch), BSD-style |
| scikit-learn | Random forest and median imputation | [scikit-learn/scikit-learn](https://github.com/scikit-learn/scikit-learn), BSD-3-Clause |
| SimpleITK | NIfTI and physical geometry | [SimpleITK](https://github.com/SimpleITK/SimpleITK), Apache-2.0 |
